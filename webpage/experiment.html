🧪 Design

🗓️ LIU Yucheng ran the experiment from Aug 21 to Aug 27, 2026, under the supervision of Prof. HU Jishan. 📚 The problems come from Stewart’s Calculus, Section 12.6, "Cylinders and Quadric Surfaces" — a topic the supervisor teaches routinely. 📐 Each problem gives one equation in $x$, $y$, and $z$, and asks the solver to identify the surface and to draw it. Since the mathematics is standard textbook material, this page does not repeat it in detail; the technical machinery behind the agent is the part that needs explanation.

🎯 The tested subject is the development of VLM-powered Math-Capable Multimodal Agents (MCMA), a project the student worked on from Jul 25 to Aug 20, before the experiment run. The experiment run of Aug 21 to Aug 27 evaluates that project.

🗂️ Three problem groups cover 24 exercises.

The printed question arrives as an image, not as text. ✏️ The answer must include a drawing, not only a sentence. This one requirement — produce a picture — is the whole point of the experiment.

🧭 Conditions

🔄 Two conditions ran side by side.

🤖 An AI model can be used by MCMA only if it is a vision-language model (VLM) and supports tool-calling.

🌐 In this experiment, we selected a set of the latest open-source VLMs that support tool-calling. They come from SiliconFlow, a service in China.

  • 🤖 Bare model: the language model alone. It reads the problem image and replies with text. It has no tools, so it can reason but cannot compute, plot, or write files.
  • 🛠️ MCMA agent: a multimodal model plus DeepAgents plus four custom tools. It can run Python, draw plots in two formats, and write a final answer file.

❌ Baseline’s Failure

📉 The bare model failed every problem. Its final output for 12.6.3 was:

$\boxed{\text{No mathematical results.}}$

The failure was 🧩 structural, not intellectual. The model reasoned about the surface correctly in many runs, but it had no way to emit a picture. A "sketch the surface" task requires a plot, and a plot requires a plotting tool. 🔇 Words alone cannot satisfy the exercise. This contrast is the crux of the experiment: capability came from the tools, not from extra math knowledge.

✅ Agents' Success

🏆 Every MCMA agent solved every problem. Each agent identified the surface, drew a 3D plot in both formats, drew a 2D cross-section in both formats, and wrote a valid boxed answer. The tools carried out every calculation and every drawing; the model made every decision.

The success was structural, just as the failure was. The agents had tools and they used them. 🧮 numpy and sympy verified every calculation; 🖼️ pyplot and PGFplots drew every plot; 📄 the results tool wrote every answer. The same model that failed without tools succeeded with tools. This is the mirror image of the baseline result.

🔁 All 20 retries came from infrastructure, not from mathematics. ⏳ 15 retries came from API rate limits; 📦 5 retries came from an output block that did not parse. ✅ None came from a wrong mathematical result.
