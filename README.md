# MCMA-Dev-Logs

Development logs of the Math-Capable Multimodal Agents (MCMA) toolchain.

## Contents

- `docs/lit-review-*`: the literature review notes.
- `docs/dev-logs-*`: one directory for each development session.
- `docs/index.html`: the rendered index of the logs.
- `main.py`, `build_explorer.py`, `fix_assets.ps1`: the scripts that render and repair the pages.

## Usage

Follow `README.md` in the repository that holds a log entry. The rendered pages are in `docs/`.
