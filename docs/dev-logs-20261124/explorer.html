🧭 How to use the explorer

📌 Each of the two panels is styled like a file explorer window. The toolbar offers these buttons: back, forward, up, and home. 🗎 opens the selected file in a new tab. 🔁 opens the selected file in the other pane, so you can compare two solutions.

📁 The address bar shows the current location with / as the separator. The address bar is editable. Type a path such as dsh-deepseek-flash/calculus-15.7.32_testing-0 and press Enter to jump straight to it. 🖱 Click a folder to open it. Click a leaf to view it in the panel viewer.

🛠 The folders mirror the raw data. The paths are canonical-solutions/<problem>/canonical-solution.html, <recipe>/<problem>/solution.html, and <recipe>/<problem>/solution/ for the scripts and figures. The two recipes are dsh-deepseek-flash (25 folders, training and test) and dsh-qwen3.8-27b-hpc (24 transfer folders).

🌐 The DeepSeek report.html pages load KaTeX from a CDN, so they need a network connection to set the math. The Qwen solution.html pages inline KaTeX and the fonts, so they open offline.
