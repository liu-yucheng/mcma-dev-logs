15.7.17 Triple Integral over the Solid E

Evaluate the triple integral $\iiint_E x \, dV$. The solid $E$ is bounded by the paraboloid $x = 4y^2 + 4z^2$ and the plane $x = 4$.
ItemContent
GivenThe solid $E$ between $x = 4y^2 + 4z^2$ and $x = 4$; integrand $f(x, y, z) = x$.
FindThe value of $\iiint_E x \, dV$.
SymbolMeaningUnit
$x, y, z$Coordinates of a point in $E$length
$A(x)$Area of the $yz$ slice of $E$ at fixed $x$area
$I$Value of the triple integrallength to the fifth

Part 1: Value of the integral

Step 1.1: The slice at fixed x is a disk

The paraboloid meets the plane where $4y^2 + 4z^2 = 4$, that is $y^2 + z^2 = 1$. For $0 \leq x \leq 4$ the slice is the disk $4y^2 + 4z^2 \leq x$ with radius $r(x) = \frac{\sqrt{x}}{2}$.

$$A(x) = \pi r(x)^2 = \frac{\pi x}{4}$$

The slice area is $A(x) = \frac{\pi x}{4}$. At $x = 4$ the grid count gives $\pi \approx 3.1416$.

The script part1_step1.py compares the exact area $\pi$ with a grid count on the unit disk, tolerance $0.02$.

A common slip reads the radius as $\sqrt{x}$ and loses the factor $\frac{1}{4}$ in the area.

Step 1.2: Stack the slices along x

Each slice carries the integrand value $x$. The triple integral becomes a one-variable integral over the slice area $A(x) = \frac{\pi x}{4}$.

$$I = \int_0^4 x A(x) \, dx = \frac{\pi}{4} \int_0^4 x^2 \, dx = \frac{\pi}{4} \cdot \frac{64}{3}$$

The exact value is $I = \frac{16\pi}{3} \approx 16.7552$.

The script part1_step2.py checks the exact value against a trapezoid pass, tolerance $0.01$.

A common slip drops the factor $x$ and integrates $A(x)$ alone, giving $4\pi$ instead of $\frac{16\pi}{3}$.

Step 1.3: Monte Carlo confirmation

A random pass over the box $0 \leq x \leq 4$, $-1 \leq y \leq 1$, $-1 \leq z \leq 1$ estimates $I$ from the hit fraction. The box volume is $16$.

$$I \approx 16 \cdot \frac{1}{n} \sum_{i \in \text{hit}} x_i, \qquad \text{hit: } 4y_i^2 + 4z_i^2 \leq x_i$$

With $n = 400000$ points the pass returns about $16.75$, close to $\frac{16\pi}{3}$.

The script part1_step3.py asserts the estimate against $\frac{16\pi}{3}$ within $0.2$.

A common slip uses the box volume $8$ and leaves the estimate off by a factor of $2$.

Answer

$\iiint_E x \, dV = \frac{16\pi}{3} \approx 16.7552$.

Notes

  • The solid is symmetric about the plane $z = 0$ and about the line $y = z$.
  • The slice radius is $r(x) = \frac{\sqrt{x}}{2}$ and reaches $1$ at $x = 4$.
