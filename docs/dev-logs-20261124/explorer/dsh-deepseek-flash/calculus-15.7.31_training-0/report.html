Six iterated integrals for one solid

Stewart, Calculus, Chapter 15.7, Exercise 31. The page derives every limit from the three defining inequalities, and every number comes from a script that the page names.

Statement

Express the integral

$$\iiint_E f(x, y, z)\,dV$$

as an iterated integral in six different ways, where $E$ is the solid bounded by the given surfaces.

$$ y = x^2, \qquad z = 0, \qquad y + 2z = 4 $$

Part 1. The region and its three projections

The problem gives three surfaces and no figure. This part turns the three surfaces into one system of inequalities. Every later limit follows from that system.

Step 1.1. Read the three surfaces as one system of inequalities

Why. A solid that three surfaces close is the set of points that lie on the inner side of each surface. The problem supplies no fourth surface, so no extra bound is available. Each bound must come from the three equations.

Reason about each surface. The equation $y = x^{2}$ does not contain $z$. It is therefore a parabolic cylinder whose axis is parallel to the $z$-axis. For a point of the solid the relation is $y \geq x^{2}$, because the other two surfaces meet the cylinder at $y = x^{2}$ and at $y = 4$, and the solid lies between them.

The equation $z = 0$ is the floor. The solid lies above it, so $z \geq 0$.

The equation $y + 2z = 4$ gives $z = (4 - y)/2$. The solid lies below this plane, so $z \leq (4 - y)/2$.

Combine the three relations. The floor and the plane together force $y \leq 4$. The reason is that $z \geq 0$ and $z \leq (4 - y)/2$ hold at the same time. The system is therefore

$$ E = \left\{(x,y,z) : x^{2} \leq y \leq 4, \quad 0 \leq z \leq \frac{4-y}{2}\right\}. $$

Result. The region $E$ is the set above the parabolic cylinder, above the floor, and below the slanted plane. The two inequalities $x^{2} \leq y$ and $0 \leq z \leq (4-y)/2$ define it completely.

Check. code/part1_verify.py draws 20000 random points in the box $[-2,2] \times [0,4] \times [0,2]$. It tests each point against the three surfaces directly ($y \geq x^{2}$, $z \geq 0$, $y + 2z \leq 4$) and against the bound chain. The script prints the count of points that the two tests classify differently, and the count is 0. The script also tests the rejected orientation $y \leq x^{2}$ and prints that this orientation admits the point with $|x| = 1000$, so the interior side of the cylinder is fixed.

Step 1.2. Project the region on each coordinate plane

Why. An integration order needs the projection of $E$ on the plane of its two outer coordinates. The projection supplies the outer limits. A projection that drops the coordinate $y$ lies on the plane $y = 0$, and a projection that drops $x$ lies on the plane $x = 0$.

Project on the plane $z = 0$, which keeps $x$ and $y$. Remove $z$ from the system. The result is $x^{2} \leq y \leq 4$. The largest value of $|x|$ is 2, and it comes from $x^{2} \leq y \leq 4$. The area of this region is

$$ \int_{-2}^{2} (4 - x^{2})\,dx = \left[4x - \frac{x^{3}}{3}\right]_{-2}^{2} = \frac{32}{3}. $$

Project on the plane $x = 0$, which keeps $y$ and $z$. Remove $x$ from the system. The result is $0 \leq y \leq 4$ and $0 \leq z \leq (4-y)/2$. This region is the triangle with corners $(0,0)$, $(4,0)$, and $(0,2)$. Its area is $\frac{1}{2} \cdot 4 \cdot 2 = 4$.

Project on the plane $y = 0$, which keeps $x$ and $z$. Remove $y$ from the system. The relation $x^{2} \leq y \leq 4$ gives $x^{2} \leq 4$, so $|x| \leq 2$. The plane gives $z \leq (4 - y)/2$, and the smallest value of $y$ is $x^{2}$. The largest value of $z$ at a fixed $x$ is therefore $(4 - x^{2})/2$. The region is

$$ 0 \leq z \leq \frac{4 - x^{2}}{2}, \qquad -2 \leq x \leq 2, $$

and its area is $\int_{-2}^{2} \frac{4 - x^{2}}{2}\,dx = \frac{16}{3}$.

Result. The three projections have the areas $32/3$, $4$, and $16/3$. The coordinate ranges are $|x| \leq 2$, $0 \leq y \leq 4$, and $0 \leq z \leq 2$. Every integration limit of this tutorial comes from one of these three regions.

Check. code/part1_verify.py computes each area twice: once by a quadrature of the region and once by the closed form above. It prints both values for each plane. Figure 1 shows the solid and the three projections side by side, and panel (b), panel (c), and panel (d) of Figure 1 carry the titles "Projection on the plane $z = 0$", "Projection on the plane $x = 0$", and "Projection on the plane $y = 0$" with the two coordinates that each panel keeps.

Step 1.3. Compute the volume of $E$ in two ways

Why. The volume is the value of $\iiint_{E} 1\,dV$. It is one number that tests a complete set of limits. Two different orders that return the same number give evidence that both limit sets are right.

First order: $dz\,dy\,dx$. The outer variable is $x$. From Step 1.2, $|x| \leq 2$. For a fixed $x$ the values of $y$ run from $x^{2}$ to 4. For a fixed $y$ the values of $z$ run from 0 to $(4 - y)/2$. Then

$$ V = \int_{-2}^{2}\int_{x^{2}}^{4} \frac{4-y}{2}\,dy\,dx = \int_{-2}^{2} \left[\frac{(4-y)^{2}}{4}\right]_{y=4}^{y=x^{2}} dx = \int_{-2}^{2} \frac{(4 - x^{2})^{2}}{4}\,dx = \frac{128}{15}. $$

Second order: $dy\,dx\,dz$. The outer variable is $z$. From Step 1.2, $0 \leq z \leq 2$. For a fixed $z$ the values of $x$ run from $-\sqrt{4-2z}$ to $\sqrt{4-2z}$. The inner variable is $y$, and $y$ runs from $x^{2}$ to $4 - 2z$, so the inner integral has the closed form $4 - 2z - x^{2}$. Then

$$ V = \int_{0}^{2}\int_{-\sqrt{4-2z}}^{\sqrt{4-2z}} \left(4 - 2z - x^{2}\right) dx\,dz = \int_{0}^{2} \frac{4}{3}\,(4 - 2z)^{3/2}\,dz = \frac{128}{15}. $$

Result. The volume is $128/15 = 8.5333333333$.

Check. code/part1_verify.py evaluates both orders with the quadrature of scipy and compares each value with the exact fraction Fraction(128, 15). It prints the exact value, the value of the order $dz\,dy\,dx$, the value of the order $dy\,dx\,dz$, and the two deviations. The script also prints the count of disagreements between the three-surface test and the bound chain, and the count is 0.

Part 2. The section of $E$ at a fixed coordinate

A section is the part of $E$ that one fixed value of one coordinate selects. Each section is a plane figure, and the area of that figure is the length of one inner interval of an integration order. This part derives the three shapes from the inequalities of Step 1.1. It does not take a shape from a drawing.

Step 2.1. Fix $x$: the section is a triangle

Why. The order $dz\,dy\,dx$ integrates over the section at a fixed $x$. The section supplies the limits of $y$ and of $z$.

Derive the shape. Put $x = c$ in the system of Step 1.1. The system becomes $c^{2} \leq y \leq 4$ and $0 \leq z \leq (4-y)/2$. The value of $y$ runs over an interval, and for each $y$ the value of $z$ runs over an interval that shrinks as $y$ grows. In the plane of the section the boundary is the line $z = 0$, the line $y = 4$, and the line $z = (4-y)/2$. These three lines cut a triangle. Its corners are $(y,z) = (c^{2},0)$, $(4,0)$, and $(c^{2},(4-c^{2})/2)$.

Compute the area. The base of the triangle is $4 - c^{2}$ and its height is $(4 - c^{2})/2$. Then

$$ A_{x}(c) = \tfrac{1}{2}\,(4 - c^{2})\,\frac{4 - c^{2}}{2} = \frac{(4 - c^{2})^{2}}{4}. $$

Read the boundary values. At $c = 0$ the corners are $(0,0)$, $(4,0)$, and $(0,2)$, and the area is $4$. At $c = 1$ the corners are $(1,0)$, $(4,0)$, and $(1,1.5)$, and the area is $2.25$. At $c = 1.9$ the corners are $(3.61,0)$, $(4,0)$, and $(3.61,0.195)$, and the area is $0.038025$. At $c = \pm 2$ the three corners merge into the single point $(4,0)$, and the area is 0.

Result. The section at a fixed $x$ is a triangle with area $(4 - x^{2})^{2}/4$. At the two boundary values $x = \pm 2$ the section is one point.

Check. code/part2_verify.py prints the corner list at each sampled value of $x$, computes the area by the shoelace formula from those corners, and compares the result with an independent integral of the height $(4-y)/2$ over the same interval of $y$. It prints both values at $c = 0$, $c = 1$, and $c = 1.9$. Panel (a) of Figure 2 shows the section at $x = 0$. Panel (d) of Figure 2 marks the three sampled values on the curve of $A_{x}$.

Step 2.2. Fix $y$: the section is a rectangle

Why. Four of the six orders integrate over the section at a fixed $y$. The section supplies the limits of $x$ and of $z$.

Derive the shape. Put $y = d$ in the system of Step 1.1. The first inequality becomes $x^{2} \leq d$, so $|x| \leq \sqrt{d}$. The second inequality becomes $0 \leq z \leq (4-d)/2$. Neither limit of $x$ depends on $z$, and neither limit of $z$ depends on $x$. The section is therefore a rectangle with corners $(-\sqrt{d},0)$, $(\sqrt{d},0)$, $(\sqrt{d},(4-d)/2)$, and $(-\sqrt{d},(4-d)/2)$ in the plane of $x$ and $z$.

Compute the area. The width is $2\sqrt{d}$ and the height is $(4-d)/2$, so

$$ A_{y}(d) = 2\sqrt{d} \cdot \frac{4-d}{2} = \sqrt{d}\,(4 - d). $$

Read the boundary values. At $d = 0.5$ the corners are $(-0.707107,0)$, $(0.707107,0)$, $(0.707107,1.75)$, $(-0.707107,1.75)$, and the area is $2.474873734$. At $d = 2$ the corners are $(-1.414214,0)$, $(1.414214,0)$, $(1.414214,1)$, $(-1.414214,1)$, and the area is $2.828427125$. At $d = 3.5$ the area is $0.935414347$. At $d = 0$ the width is 0, so the section is the segment from $(0,0)$ to $(0,2)$ along the $z$-axis. At $d = 4$ the height is 0, so the section is the segment from $(-2,0)$ to $(2,0)$ along the direction of $x$. Each of these two sections is a segment, and neither is a point.

Result. The section at a fixed $y$ is a rectangle with area $\sqrt{y}\,(4-y)$. At $y = 0$ and at $y = 4$ the section is a segment.

Check. code/part2_verify.py prints the corner list at each sampled value of $y$, computes the area by the shoelace formula, and compares the result with the independent product of the two interval lengths. The script also prints the number of distinct corners at $y = 0$ and at $y = 4$, and that number is 2 at each value. Panel (b) of Figure 2 shows the section at $y = 2$.

Step 2.3. Fix $z$: the section is a parabolic segment

Why. The two orders with $z$ outermost integrate over the section at a fixed $z$. The section supplies the limits of $x$ and of $y$.

Derive the shape. Put $z = e$ in the system of Step 1.1. The second inequality becomes $0 \leq e \leq (4-y)/2$, which is the same as $y \leq 4 - 2e$. Together with $x^{2} \leq y$ the section is

$$ x^{2} \leq y \leq 4 - 2e, \qquad -\sqrt{4-2e} \leq x \leq \sqrt{4-2e}. $$

The lower boundary is the parabola $y = x^{2}$. The upper boundary is the horizontal line $y = 4 - 2e$. The section is the part of the parabolic region that lies below that line.

Compute the area. Integrate the height $4 - 2e - x^{2}$ over the interval of $x$:

$$ A_{z}(e) = \int_{-\sqrt{4-2e}}^{\sqrt{4-2e}} \left(4 - 2e - x^{2}\right) dx = \frac{4}{3}\,(4 - 2e)^{3/2}. $$

Read the boundary values. At $e = 0$ the limits of $x$ are $\pm 2$, and the area is $10.666666667$. At $e = 1$ the limits of $x$ are $\pm 1.414214$, and the area is $3.771236166$. At $e = 1.5$ the limits of $x$ are $\pm 1$, and the area is $1.333333333$. At $e = 2$ the limits of $x$ merge at 0 and the upper line meets the parabola at $y = 0$, so the section is the single point $(0,0)$ in the plane of $x$ and $y$.

Result. The section at a fixed $z$ is a parabolic segment with area $\frac{4}{3}(4 - 2z)^{3/2}$. At $z = 2$ the section is one point.

Check. code/part2_verify.py computes the area at each sampled value of $z$ in two ways: by an adaptive quadrature of the height (4 - 2e - x squared) over the interval of $x$, and by the closed form above. It prints both values and the difference. The script also prints the number of distinct corners at $z = 2$, and that number is 1. Panel (c) of Figure 2 shows the section at $z = 0.5$.

Step 2.4. Integrate the area of the section over the parameter

Why. The volume is the integral of the area of a section over the parameter of the family. This statement is the reason that the six orders agree: each order sums the same sections in a different sequence. If the three slab integrals return the same number, then the six orders must return that number too.

Integrate the three area functions. The parameter of the first family is $x$, and the values run over $[-2,2]$:

$$ \int_{-2}^{2} \frac{(4 - x^{2})^{2}}{4}\,dx = \frac{128}{15}. $$

The parameter of the second family is $y$, and the values run over $[0,4]$:

$$ \int_{0}^{4} \sqrt{y}\,(4 - y)\,dy = \frac{128}{15}. $$

The parameter of the third family is $z$, and the values run over $[0,2]$:

$$ \int_{0}^{2} \frac{4}{3}\,(4 - 2z)^{3/2}\,dz = \frac{128}{15}. $$

Result. Each of the three slab integrals equals $128/15 = 8.5333333333$, which is the volume of Step 1.3. Each integration bound follows from the range of the parameter that Step 1.2 derived, so no bound comes from a drawing.

Check. code/part2_verify.py evaluates each slab integral with a quadrature and compares the value with the exact fraction Fraction(128, 15). It prints the three numerical values, the exact value, and the three deviations. The script also prints the three sampled areas of each family together with the product of the interval lengths that produced them, so the sampled values of panels (a), (b), and (c) of Figure 2 are the same numbers that the page prints.

Part 3. The two orders with $x$ outermost

An order names its differentials from the inside to the outside. In the order $dz\,dy\,dx$ the inner integral is in $z$, the middle integral is in $y$, and the outer integral is in $x$. The outer variable chooses the section, and the two inner variables run over that section.

Step 3.1. Write the order $dz\,dy\,dx$

Why. The outer variable is $x$, so the section is the one at a fixed $x$. Step 2.1 gives its shape. The inner integral is in $z$, so the section is cut into vertical pieces: a fixed value of $y$ selects one vertical piece that runs from the floor to the slanted plane.

Derive the limits from the outside inward. The outer variable is $x$. Step 1.2 gives $-2 \leq x \leq 2$. The middle variable is $y$. In the section at a fixed $x$ the values of $y$ run from the parabola to the plane, so $x^{2} \leq y \leq 4$. The inner variable is $z$. At a fixed $x$ and a fixed $y$ the values of $z$ run from the floor to the plane, so $0 \leq z \leq (4 - y)/2$. The order is

$$ \iiint_{E} f\,dV = \int_{-2}^{2}\int_{x^{2}}^{4}\int_{0}^{(4-y)/2} f(x,y,z)\,dz\,dy\,dx. $$

Read the inner piece. At a fixed $x$ the inner piece is a vertical segment of length $(4 - y)/2$. That length becomes small as $y$ approaches 4, and its largest value $(4 - x^{2})/2$ occurs at $y = x^{2}$.

Result. The first order is $\int_{-2}^{2}\int_{x^{2}}^{4}\int_{0}^{(4-y)/2} f\,dz\,dy\,dx$. Its value for $f = 1$ is $8.5333333333$.

Check. code/part3_verify.py compares this order with the order of Step 3.2. It prints the value of each order for $f = 1$, for $f = x^{2} + y + z$, and for $f = xyz$, and it prints the smallest length of an inner interval over a grid of the section. That smallest length is $1.994950 \times 10^{-2}$, so no inner interval collapses. Panel (a) of Figure 3 draws the vertical inner pieces at $x = 1$.

Step 3.2. Write the order $dy\,dz\,dx$

Why. The outer variable is again $x$, so the section is the same triangle. The inner integral is now in $y$, so the section is cut into horizontal pieces: a fixed value of $z$ selects one horizontal piece that runs from the parabola to the plane.

Derive the limits from the outside inward. The outer variable is $x$, and $-2 \leq x \leq 2$. The middle variable is $z$. In the section at a fixed $x$ the largest value of $z$ is at $y = x^{2}$, so $0 \leq z \leq (4 - x^{2})/2$. The inner variable is $y$. At a fixed $x$ and a fixed $z$ the plane gives $y \leq 4 - 2z$, and the parabola gives $y \geq x^{2}$. The order is

$$ \iiint_{E} f\,dV = \int_{-2}^{2}\int_{0}^{(4-x^{2})/2}\int_{x^{2}}^{4-2z} f(x,y,z)\,dy\,dz\,dx. $$

Read the inner piece. At a fixed $x$ and a fixed $z$ the inner piece is a horizontal segment of length $4 - 2z - x^{2}$. That length is 0 at $z = (4 - x^{2})/2$, which is the top corner of the triangle.

Compare the two orders of this part. The two orders cover the same triangle, because Step 2.1 gives one shape at a fixed $x$ and both orders use that shape. One order cuts the triangle into vertical pieces and the other order cuts it into horizontal pieces. Each of the two orders has one inner integral, and neither order splits an inner integral into two integrals.

Result. The second order is $\int_{-2}^{2}\int_{0}^{(4-x^{2})/2}\int_{x^{2}}^{4-2z} f\,dy\,dz\,dx$. Its value for $f = 1$ is $8.5333333333$, which is the value of the order of Step 3.1.

Check. code/part3_verify.py prints the value of both orders for three integrands and the absolute difference of each pair. Each difference is below $10^{-12}$. The script also tests 5000 random points against the limits of both orders of this part and prints the count of disagreements, and that count is 0 for each of the two orders. The six limit sets together are tested in Step 6.1. Panel (b) of Figure 3 draws the horizontal inner pieces at $x = 1$, and the panel title of Figure 3 states that each piece runs from $x^{2}$ to $4 - 2z$.

Part 4. The two orders with $y$ outermost

The outer variable is $y$, so the section is the one at a fixed $y$. Step 2.2 gives its shape: a rectangle. Neither limit of the rectangle depends on the other coordinate, so both orders of this part have a product structure and neither inner integral needs a split.

Step 4.1. Write the order $dz\,dx\,dy$

Why. The inner integral is in $z$ and the middle integral is in $x$. In the rectangle at a fixed $y$ the value of $z$ runs from the floor to the slanted plane, and that range does not depend on $x$. The inner integral is therefore a single integral.

Derive the limits from the outside inward. The outer variable is $y$, and Step 1.2 gives $0 \leq y \leq 4$. The middle variable is $x$. The parabola gives $x^{2} \leq y$, so $-\sqrt{y} \leq x \leq \sqrt{y}$. The inner variable is $z$, and $0 \leq z \leq (4 - y)/2$. The order is

$$ \iiint_{E} f\,dV = \int_{0}^{4}\int_{-\sqrt{y}}^{\sqrt{y}}\int_{0}^{(4-y)/2} f(x,y,z)\,dz\,dx\,dy. $$

Result. The third order is $\int_{0}^{4}\int_{-\sqrt{y}}^{\sqrt{y}}\int_{0}^{(4-y)/2} f\,dz\,dx\,dy$. Its value for $f = 1$ is $8.5333333333$.

Check. code/part4_verify.py compares this order with the order of Step 4.2 for three integrands. It prints the value of each order, the absolute difference, and the smallest length of an inner interval over a grid of the section. That smallest length is $2.500000 \times 10^{-2}$, so no inner interval collapses. The script also prints the corner list of the section at $y = 0$ and at $y = 4$, and each list holds 2 corners, so each of those sections is a segment.

Step 4.2. Write the order $dx\,dz\,dy$

Why. The outer variable is $y$ again, so the section is the same rectangle. The inner integral is now in $x$, and the interval of $x$ does not depend on $z$, so the inner integral is again a single integral.

Derive the limits from the outside inward. The outer variable is $y$, and $0 \leq y \leq 4$. The middle variable is $z$, and $0 \leq z \leq (4 - y)/2$. The inner variable is $x$, and the parabola gives $-\sqrt{y} \leq x \leq \sqrt{y}$. The order is

$$ \iiint_{E} f\,dV = \int_{0}^{4}\int_{0}^{(4-y)/2}\int_{-\sqrt{y}}^{\sqrt{y}} f(x,y,z)\,dx\,dz\,dy. $$

Compare the two orders of this part. Both orders integrate over the same rectangle. The order $dz\,dx\,dy$ cuts the rectangle into vertical pieces and the order $dx\,dz\,dy$ cuts it into horizontal pieces. Because the rectangle is a product of two intervals, each order factors into a product of two integrals when the integrand is a product of a function of one variable and a function of another variable.

Result. The fourth order is $\int_{0}^{4}\int_{0}^{(4-y)/2}\int_{-\sqrt{y}}^{\sqrt{y}} f\,dx\,dz\,dy$. Its value for $f = 1$ is $8.5333333333$, which is the value of the order of Step 4.1.

Check. code/part4_verify.py prints the value of both orders for the three integrands and the absolute difference of each pair. Each difference is below $10^{-12}$. The corner list of the section at $y = 2$ is in the printout of code/part2_verify.py that Step 2.2 cites: the interval of $x$ is $[-1.414214, 1.414214]$ and the interval of $z$ is $[0, 1]$, and the four corners give a rectangle.

Part 5. The two orders with $z$ outermost

The outer variable is $z$, so the section is the one at a fixed $z$. Step 2.3 gives its shape: a parabolic segment. The values of $z$ run from 0 to 2, and the top value 2 is the value at which the segment shrinks to one point.

Step 5.1. Write the order $dy\,dx\,dz$

Why. The inner integral is in $y$ and the middle integral is in $x$. In the segment at a fixed $z$ the value of $y$ runs from the parabola to the horizontal line, and the limits of $y$ depend on $x$. The inner integral is therefore a single integral, and the middle interval of $x$ is set by the widest row of the segment.

Derive the limits from the outside inward. The outer variable is $z$. Step 1.2 gives $0 \leq z \leq 2$. The middle variable is $x$. The section at a fixed $z$ has $x^{2} \leq 4 - 2z$, so $-\sqrt{4-2z} \leq x \leq \sqrt{4-2z}$. The inner variable is $y$, and $x^{2} \leq y \leq 4 - 2z$. The order is

$$ \iiint_{E} f\,dV = \int_{0}^{2}\int_{-\sqrt{4-2z}}^{\sqrt{4-2z}}\int_{x^{2}}^{4-2z} f(x,y,z)\,dy\,dx\,dz. $$

Read the inner piece. At a fixed $x$ and a fixed $z$ the inner piece is a vertical segment of length $4 - 2z - x^{2}$. That length is 0 at the two ends of the interval of $x$.

Result. The fifth order is $\int_{0}^{2}\int_{-\sqrt{4-2z}}^{\sqrt{4-2z}}\int_{x^{2}}^{4-2z} f\,dy\,dx\,dz$. Its value for $f = 1$ is $8.5333333333$.

Check. code/part5_verify.py compares this order with the order of Step 5.2 for three integrands. It prints the value of each order, the absolute difference, and the smallest length of an inner interval over a grid of the section. That smallest length is $3.960000 \times 10^{-3}$, so no inner interval collapses. Panel (a) of Figure 4 draws the vertical inner pieces at $z = 0.5$.

Step 5.2. Write the order $dx\,dy\,dz$

Why. The outer variable is $z$ again, so the section is the same parabolic segment. The inner integral is now in $x$. The segment is symmetric about the plane $x = 0$, so the limits of $x$ are $-\sqrt{y}$ and $\sqrt{y}$ for every fixed $y$.

Derive the limits from the outside inward. The outer variable is $z$, and $0 \leq z \leq 2$. The middle variable is $y$. In the segment at a fixed $z$ the value of $y$ runs from 0 to $4 - 2z$. The inner variable is $x$, and $x^{2} \leq y$ gives $-\sqrt{y} \leq x \leq \sqrt{y}$. The order is

$$ \iiint_{E} f\,dV = \int_{0}^{2}\int_{0}^{4-2z}\int_{-\sqrt{y}}^{\sqrt{y}} f(x,y,z)\,dx\,dy\,dz. $$

Compare the two orders of this part. Both orders integrate over the same segment. Each order has one inner integral and one middle integral, and neither order splits an inner integral into two integrals. The order $dy\,dx\,dz$ cuts the segment into vertical pieces and the order $dx\,dy\,dz$ cuts it into horizontal pieces. The horizontal pieces have length $2\sqrt{y}$, and that length grows with $y$, so the widest piece is at $y = 4 - 2z$.

Result. The sixth order is $\int_{0}^{2}\int_{0}^{4-2z}\int_{-\sqrt{y}}^{\sqrt{y}} f\,dx\,dy\,dz$. Its value for $f = 1$ is $8.5333333333$, which is the value of the order of Step 5.1.

Check. code/part5_verify.py prints the value of both orders for the three integrands and the absolute difference of each pair. Each difference is below $10^{-12}$. The script code/part5_figure4.py prints the interval of $x$ at $y = 0.5$, $y = 1.5$, and $y = 2.5$ when it draws panel (b) of Figure 4, and these intervals are $[-0.707107, 0.707107]$, $[-1.224745, 1.224745]$, and $[-1.581139, 1.581139]$.
