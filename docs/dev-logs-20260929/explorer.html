🧭 How to use the explorer

Each of the two independent panels is styled like a file explorer window. The toolbar on top offers navigation buttons (back, forward, up, home). The address bar shows the current location with / as the separator. The address bar is editable. Type a path such as deepseek-flash/calculus-15.7.17 and press Enter to jump straight to it. The single main view lists the subdirectories and files of the current folder. The view shows . (current folder) and .. (parent folder) at the top. Click a folder to open it. Click a leaf (canonical-solution.html, remarks.html, qna.html) to view it in the panel’s viewer. Everything opens with a single click. Both panes start at the root. The root holds canonical-solutions/ and the model directories.

📁 The folders mirror explorer/. The paths are canonical-solutions/<problem>/canonical-solution.html, <model>/<problem>/remarks.html, and <model>/<problem>/<chat>/qna.html. Each chat transcript is also reachable through a shortcut leaf at <model>/<problem>/qna_<timestamp>.html. This leaf redirects to the deep qna.html.
