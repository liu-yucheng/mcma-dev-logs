🧪 Design

🗓️ LIU Yucheng ran the experiment from Sep 23 to Sep 29, 2026. The experiment evaluated the MCMA development done from Aug 25 to Sep 22. 📚 The problems come from Calculus, Early Transcendentals, Sections 15.7, "Triple Integrals," 15.8, "Triple Integrals in Cylindrical Coordinates," and 15.9, "Triple Integrals in Spherical Coordinates." 📐 Each problem gives a solid region in $x$, $y$, and $z$. Each problem asks the solver to set up the volume integral and to show the region with plots. The mathematics is standard textbook material. This page does not repeat it in detail. The technical machinery behind the agent is the part that needs explanation.

🎯 The tested subject is the development of VLM-powered Math-Capable Multimodal Agents (MCMA). More specifically, the subject is the MCMA software updates that LIU Yucheng worked on from Aug 25 to Sep 22, before the experiment run. The experiment run of Sep 23 to Sep 29 evaluates the project.

🗂️ Three problem groups cover 24 exercises.

The 15.7 problems are 17, 18, 20 – 23, 27 – 32, 39, 40, 46, 47, 49, 50, 54, and 55. The 15.8 problems are 14 and 26. The 15.9 problems are 43 and 45.

📸 A typical example is 15.7.17, the solid under the paraboloid $x=4(y^2+z^2)$ and the plane $x=4$. The printed question arrives as an image, not as text. ✏️ The answer must include plots that show the region and its cross-sections, not only a sentence. This one requirement — produce pictures — is the whole point of the experiment.

🧭 Conditions

🔄 Two conditions ran side by side.

🤖 An AI model can be used by MCMA only if it is a vision-language model (VLM) and supports tool-calling.

🌐 In this experiment, we selected a set of the latest open-source VLMs that support tool-calling. AI service provider SiliconFlow (China) hosts these models.

  • 🤖 Tools disabled: the language model alone. It reads the problem image and replies with text. It has no tools, so it can reason but cannot compute, plot, or write files.
  • 🛠️ MCMA agent: a multimodal model plus DeepAgents plus four custom tools. It can run Python, draw plots in two formats, and write a final answer file.

🗂️ Data planned to collect

This experiment plans to collect statistical data in four categories. For each of the six configurations it plans to record:

  • Success and attempt counts — solved cases, first-attempt solves, total and average attempts, and re-attempts, scored per the remarks.html convention in the Results Explorer.
  • Token usage — from each run’s usages.json: input and output tokens (totals and averages per attempt), with cache-read input and reasoning-output breakdowns where a model reports them.
  • Time usage — from usages.json: per-attempt chat durations and total chat time.
  • Cost — from each run’s costs.json: estimated spend in CNY and USD, with peak- and off-peak pricing where a model quotes both.

The success and attempt data come from the per-problem chat_<timestamp>/ records and the canonical-solutions/ scans. The token, time, and cost data come from the audit functions the MCMA repository added, stored in the per-configuration usages.json and costs.json files. The Results Briefing chapter reports each category for all six configurations.

❌ Baseline’s Failure

Recent updates to the MCMA repository added token- and time-usage audit functions: each configuration records a usages.json and a costs.json. The Results Briefing chapter reports token, time, and cost consumption for all six configurations.

📉 The tools-disabled model failed every problem. It reasoned about the region in some runs, but it had no way to emit a picture. Its final outputs for every problem never included a plot.

The failure was 🧩 structural, not intellectual. A "sketch the region" task requires a plot, and a plot requires a plotting tool. 🔇 Words alone cannot satisfy the exercise. This contrast is the crux of the experiment: capability came from the tools, not from extra math knowledge.

✅ Agents’ Success

🏆 The MCMA agents produced plots in 118 of the 120 cases, each within 5 attempts. Each successful agent identified the region, set up the integral, drew a plot of the region, and wrote a boxed answer. The tools carried out every calculation and every drawing. The model made every decision.

The success was structural, just as the failure was. The agents had tools and they used them. 🧮 numpy and sympy verified every calculation. 🖼️ pyplot and PGFplots drew every plot. 📄 The results tool wrote every answer. The same model that failed without tools succeeded with tools. This is the mirror image of the baseline result.

🔁 Not every case succeeded on the first try. Five models produced almost all of their plots on the first attempt. Only gemma-4-26b-a4b-it re-attempted often: it took 42 attempts across its 24 problems, and on two of them (15.7.23 and 15.7.50) none of the five attempts included an image in the final solution. 📉 Those two cases are the only failures in the 120.
