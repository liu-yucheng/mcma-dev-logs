## Setting Up the Region The solid $E$ is a **cylinder of radius 3 with axis along the $x$-axis**, extending from $x=-2$ to $x=2$: $$E = \{(x,y,z) : -2 \le x \le 2,\ \ y^2 + z^2 \le 9\}.$$ Because $E$ is a cylinder whose **axis is the $x$-axis**, the bounds on $x$ are always simple ($-2 \le x \le 2$), while the bounds on $y$ and $z$ depend on each other through the disk $y^2+z^2 \le 9$. Image `pyplot_overview.png` not found. **Key observations from the projections:** | Projection onto | Region | Why | |---|---|---| | $xy$-plane | Rectangle $[-2,2] \times [-3,3]$ | $x$ free, $y$ ranges over disk's range | | $xz$-plane | Rectangle $[-2,2] \times [-3,3]$ | $x$ free, $z$ ranges over disk's range | | $yz$-plane | Disk $y^2+z^2 \le 9$ | the circular cross-section | > **Volume check.** $\text{Vol}(E) = \pi r^2 h = \pi(3)^2(4) = 36\pi$. We verified below that every iterated integral below reproduces this value. Image `pyplot_slices.png` not found. ## The Six Iterated Integrals For each order, the strategy is: project $E$ onto the plane of the two outer variables to find their bounds; then, holding those fixed, find the bounds on the innermost variable. --- ### Order 1: $\displaystyle \iiint_E f\,dV = \int_{-2}^{2}\!\!\int_{-3}^{3}\!\!\int_{-\sqrt{9-y^{2}}}^{\sqrt{9-y^{2}}} f\,dz\,dy\,dx$ - **Outer ($x$):** $-2 \le x \le 2$. - **Middle ($y$):** $-3 \le y \le 3$ (from projection onto $xy$-plane). - **Inner ($z$):** For fixed $x,y$: $y^2+z^2 \le 9 \Rightarrow z \in \bigl[-\sqrt{9-y^2},\,\sqrt{9-y^2}\bigr]$. --- ### Order 2: $\displaystyle \iiint_E f\,dV = \int_{-3}^{3}\!\!\int_{-2}^{2}\!\!\int_{-\sqrt{9-y^{2}}}^{\sqrt{9-y^{2}}} f\,dz\,dx\,dy$ - **Outer ($y$):** $-3 \le y \le 3$ (projection onto $yz$-plane gives a disk, so $y$ alone ranges over $[-3,3]$). - **Middle ($x$):** $x$ is independent of $y,z$, so $-2 \le x \le 2$. - **Inner ($z$):** $\pm\sqrt{9-y^2}$ (as in Order 1). --- ### Order 3: $\displaystyle \iiint_E f\,dV = \int_{-2}^{2}\!\!\int_{-3}^{3}\!\!\int_{-\sqrt{9-z^{2}}}^{\sqrt{9-z^{2}}} f\,dy\,dz\,dx$ - **Outer ($x$):** $-2 \le x \le 2$. - **Middle ($z$):** $-3 \le z \le 3$ (projection onto $xz$-plane is a rectangle). - **Inner ($y$):** For fixed $x,z$: $y \in \bigl[-\sqrt{9-z^2},\,\sqrt{9-z^2}\bigr]$. --- ### Order 4: $\displaystyle \iiint_E f\,dV = \int_{-3}^{3}\!\!\int_{-2}^{2}\!\!\int_{-\sqrt{9-z^{2}}}^{\sqrt{9-z^{2}}} f\,dy\,dx\,dz$ - **Outer ($z$):** $-3 \le z \le 3$. - **Middle ($x$):** $-2 \le x \le 2$. - **Inner ($y$):** $\pm\sqrt{9-z^2}$. --- ### Order 5: $\displaystyle \iiint_E f\,dV = \int_{-3}^{3}\!\!\int_{-\sqrt{9-y^{2}}}^{\sqrt{9-y^{2}}}\!\!\int_{-2}^{2} f\,dx\,dz\,dy$ - **Outer ($y$):** $-3 \le y \le 3$. - **Middle ($z$):** For fixed $y$: $z \in \bigl[-\sqrt{9-y^2},\,\sqrt{9-y^2}\bigr]$ (the disk's $z$-slice). - **Inner ($x$):** $x$ is independent, so $-2 \le x \le 2$. --- ### Order 6: $\displaystyle \iiint_E f\,dV = \int_{-3}^{3}\!\!\int_{-\sqrt{9-z^{2}}}^{\sqrt{9-z^{2}}}\!\!\int_{-2}^{2} f\,dx\,dy\,dz$ - **Outer ($z$):** $-3 \le z \le 3$. - **Middle ($y$):** For fixed $z$: $y \in \bigl[-\sqrt{9-z^2},\,\sqrt{9-z^2}\bigr]$. - **Inner ($x$):** $x$ is independent, so $-2 \le x \le 2$. ## Numerical Verification Taking $f(x,y,z) \equiv 1$ (volume), every order above was checked with symbolic integration and yields $$\iiint_E 1\,dV \;=\; 36\pi \;\approx\; 113.0973,$$ matching $\pi r^2 h = \pi(9)(4)$. ✓ ## Summary Table | Order | Outer | Middle | Inner | |:-:|:-:|:-:|:-:| | $dz\,dy\,dx$ | $x\in[-2,2]$ | $y\in[-3,3]$ | $z\in[\pm\sqrt{9-y^2}]$ | | $dz\,dx\,dy$ | $y\in[-3,3]$ | $x\in[-2,2]$ | $z\in[\pm\sqrt{9-y^2}]$ | | $dy\,dz\,dx$ | $x\in[-2,2]$ | $z\in[-3,3]$ | $y\in[\pm\sqrt{9-z^2}]$ | | $dy\,dx\,dz$ | $z\in[-3,3]$ | $x\in[-2,2]$ | $y\in[\pm\sqrt{9-z^2}]$ | | $dx\,dz\,dy$ | $y\in[-3,3]$ | $z\in[\pm\sqrt{9-y^2}]$ | $x\in[-2,2]$ | | $dx\,dy\,dz$ | $z\in[-3,3]$ | $y\in[\pm\sqrt{9-z^2}]$ | $x\in[-2,2]$ | **Geometric takeaway.** Because $E$ is a right cylinder, the axis variable ($x$) is always independent of the others — that's why $x$ integrates cleanly from $-2$ to $2$ no matter where it appears.
