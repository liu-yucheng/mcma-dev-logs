# Solution: Triple Integral Maximization ## Part (a): Finding the Optimal Region E **Strategy.** Let $f(x,y,z) = 1 - x^2 - 2y^2 - 3z^2$ denote the integrand. For any region $E$, if we enlarge $E$ by adding a small piece $dE$ on which $f \geq 0$, the integral increases; if we add a piece where $f < 0$, the integral decreases. Therefore the integral is **maximized precisely when we keep every point where $f \geq 0$ and discard every point where $f < 0$.** Setting $f(x,y,z) = 0$ gives the surface $$x^2 + 2y^2 + 3z^2 = 1,$$ which is an ellipsoid with semi-axes $1,\; 1/\sqrt{2},\; 1/\sqrt{3}$. The integrand is - positive inside the ellipsoid, - zero on the surface, - negative outside. Hence the maximizing region is the closed solid ellipsoid $$\boxed{\;E = \{(x,y,z) : x^2 + 2y^2 + 3z^2 \leq 1\}\;}$$ --- [PGFplots / tikz plot.](./pgfplots_0.tex)

--- **Visualization of $E$.** The ellipsoid is shown above. It is a sphere stretched along the $x$-axis (semi-axis $1$), squeezed along $y$ (semi-axis $1/\sqrt{2}\approx 0.707$), and squeezed more along $z$ (semi-axis $1/\sqrt{3}\approx 0.577$). --- ## Part (b): Computing the Maximum Value **Step 1 — Rescale the ellipsoid to the unit ball.** Make the substitution $$u = x,\quad v = \sqrt{2}\,y,\quad w = \sqrt{3}\,z.$$ Then $x^2 + 2y^2 + 3z^2 = u^2 + v^2 + w^2$, so $E$ becomes the unit ball $B = \{(u,v,w) : u^2+v^2+w^2 \leq 1\}$, and the integrand simplifies to $1 - u^2 - v^2 - w^2$. **Step 2 — Compute the Jacobian.** Since $x = u$, $y = v/\sqrt{2}$, $z = w/\sqrt{3}$, $$\left|\frac{\partial(x,y,z)}{\partial(u,v,w)}\right| = \frac{1}{\sqrt{2}\cdot\sqrt{3}} = \frac{1}{\sqrt{6}}.$$ Therefore $$\iiint_E \bigl(1 - x^2 - 2y^2 - 3z^2\bigr)\,dV \;=\; \frac{1}{\sqrt{6}}\iiint_B \bigl(1 - u^2 - v^2 - w^2\bigr)\,du\,dv\,dw.$$ **Step 3 — Use spherical coordinates.** With $(u,v,w) = (\rho\sin\phi\cos\theta,\, \rho\sin\phi\sin\theta,\, \rho\cos\phi)$, $$\iiint_B (1-\rho^2)\,dV \;=\; \int_0^{2\pi}\!\!\int_0^{\pi}\!\!\int_0^{1}(1-\rho^2)\,\rho^2\sin\phi\;d\rho\,d\phi\,d\theta.$$ This separates: - Angular part: $\displaystyle\int_0^{2\pi}\!d\theta\int_0^{\pi}\!\sin\phi\,d\phi = 2\pi\cdot 2 = 4\pi.$ - Radial part: $\displaystyle\int_0^{1}(\rho^2 - \rho^4)\,d\rho = \frac{1}{3} - \frac{1}{5} = \frac{2}{15}.$ Combining, $$\iiint_E (1 - x^2 - 2y^2 - 3z^2)\,dV = \frac{1}{\sqrt{6}}\cdot 4\pi\cdot\frac{2}{15} = \frac{8\pi}{15\sqrt{6}}.$$ **Step 4 — Rationalize.** Multiplying numerator and denominator by $\sqrt 6$, $$\frac{8\pi}{15\sqrt{6}} = \frac{8\pi\sqrt{6}}{90} = \frac{4\pi\sqrt{6}}{45}.$$ **Step 5 — Verify.** Using `sympy`: 
>>> from sympy import integrate, sin, pi, sqrt, symbols
>>> rho, phi, theta = symbols('rho phi theta', positive=True)
>>> integrate(integrate(integrate((1-rho**2)*rho**2*sin(phi)/sqrt(6),
...          (rho,0,1)), (phi,0,pi)), (theta,0,2*pi))
4*sqrt(6)*pi/45
A Monte Carlo check over the bounding box $[-1,1]\times[-1/\sqrt{2},1/\sqrt{2}]\times[-1/\sqrt{3},1/\sqrt{3}]$ (5 million samples) gives $0.6846$, matching $4\pi\sqrt{6}/45 \approx 0.6840$. **Maximum value:** $$\boxed{\;\iiint_E\bigl(1-x^2-2y^2-3z^2\bigr)\,dV_{\max} = \frac{4\pi\sqrt{6}}{45}\;}$$ Numerically, $\dfrac{4\pi\sqrt{6}}{45} \approx 0.6840$. --- [PGFplots / tikz plot.](./pgfplots_1.tex)
