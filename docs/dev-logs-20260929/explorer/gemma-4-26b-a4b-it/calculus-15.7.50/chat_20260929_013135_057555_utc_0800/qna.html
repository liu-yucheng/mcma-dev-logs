From $y^2 + z^2 = 9$ and $z \ge 0$, we have $0 \le z \le \sqrt{9 - y^2}$. Since $z \ge 0$, we must have $y^2 \le 9$, so $0 \le y \le 3$. For a fixed $y$, the bounds for $x$ are $0 \le x \le y/3$. The density function is $\rho(x, y, z) = x^2 + y^2$. ## 2.
