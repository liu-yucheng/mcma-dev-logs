# Problem Solution The problem asks us to find the mass, center of mass, and moment of inertia about the $z$-axis for a solid $E$ in the first octant. ## 1. Problem Setup ### Region of Integration $E$ The solid $E$ is in the first octant ($x \ge 0, y \ge 0, z \ge 0$) and is bounded by: - The cylinder: $x^2 + y^2 = 1$ - The planes: $y = z$, $x = 0$, and $z = 0$. In the first octant, the projection of the cylinder $x^2 + y^2 = 1$ onto the $xy$-plane is the quarter-disk $D = \{(x, y) : x^2 + y^2 \le 1, x \ge 0, y \ge 0\}$. The limits for $z$ are bounded by the planes $z = 0$ and $z = y$. Thus, for a given $(x, y) \in D$, we have $0 \le z \le y$. The region $E$ can be described as: $$E = \{(x, y, z) : 0 \le x \le 1, 0 \le y \le \sqrt{1-x^2}, 0 \le z \le y\}$$ ### Density Function The density function is given by: $$\rho(x, y, z) = 1 + x + y + z$$ --- ## 2. Calculations ### (a) Mass of $E$ The mass $M$ is given by the triple integral of the density function over the region $E$: $$M = \iiint_E \rho(x, y, z) \, dV = \int_0^1 \int_0^{\sqrt{1-x^2}} \int_0^y (1 + x + y + z) \, dz \, dy \, dx$$ Using the results from our computation: $$M = \frac{3\pi}{32} + \frac{11}{24}$$ ### (b) Center of Mass The center of mass $(\bar{x}, \bar{y}, \bar{z})$ is calculated using: $$\bar{x} = \frac{1}{M} \iiint_E x \rho(x, y, z) \, dV$$ $$\bar{y} = \frac{1}{M} \iiint_E y \rho(x, y, z) \, dV$$ $$\bar{z} = \frac{1}{M} \iiint_E z \rho(x, y, z) \, dV$$ From our computations: - $\bar{x} = \frac{7}{24 \left(\frac{3\pi}{32} + \frac{11}{24}\right)}$ - $\bar{y} = \frac{\frac{\pi}{16} + \frac{4}{15}}{\frac{3\pi}{32} + \frac{11}{24}}$ - $\bar{z} = \frac{\frac{\pi}{32} + \frac{13}{90}}{\frac{3\pi}{32} + \frac{11}{24}}$ ### (c) Moment of Inertia about the $z$-axis The moment of inertia about the $z$-axis, $I_z$, is given by: $$I_z = \iiint_E (x^2 + y^2) \rho(x, y, z) \, dV$$ From our computations: $$I_z = \frac{\pi}{16} + \frac{17}{60}$$ --- ## Summary of Results The exact values for the quantities are: (a) **Mass:** $$\boxed{M = \frac{3\pi}{32} + \frac{11}{24}}$$ (b) **Center of Mass:** $$\boxed{\left( \bar{x}, \bar{y}, \bar{z} \right) = \left( \frac{7}{24(3\pi/32 + 11/24)}, \frac{\pi/16 + 4/15}{3\pi/32 + 11/24}, \frac{\pi/32 + 13/90}{3\pi/32 + 11/24} \right)}$$ (c) **Moment of Inertia about the $z$-axis:** $$\boxed{I_z = \frac{\pi}{16} + \frac{17}{60}}$$ --- [PGFplots / tikz plot.](./pgfplots_0.tex)
