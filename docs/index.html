Dev Log Explorer

Browse each dev log by date in a single-pane Windows 11 style explorer. Shortcuts named dev-logs-<date>-index.html open the index of each log; a single click opens a folder or a file.

How to use the explorer

The pane is styled like a Windows 11 File Explorer window. The toolbar on top offers navigation buttons (back, forward, up, home); the address bar shows the current location with / as the separator and is editable — type a path such as dev-logs-20260824 and press Enter to jump straight to it. The main view lists the subdirectories and files of the current folder, with . (current folder) and .. (parent folder) at the top. Single-click a directory to open it; single-click a shortcut named dev-logs-<date>-index.html (or another file) to view it in the lower half; double-click it to open the file in a new browser window.

Each shortcut mirrors docs/dev-logs-<date>/index.html. Add a new dev log by extending RESULTS_TREE below with a dev-logs-<date> folder and its dev-logs-<date>-index.html shortcut.
