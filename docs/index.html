Can Open-Source VLMs Teach Advanced Math?

The supervisor asked whether current open-source vision-language models can support multimodal tutoring of advanced mathematics. The experiment answers this question with data.

📋 Summary

🎯 The question under test. Can current open-source vision-language models (VLMs) support multimodal tutoring of advanced mathematics? This page presents the results of the experiment in dev-logs-20260824.

🧭 The purpose follows from a principle. An AI teaching assistant for advanced math must first understand how to solve advanced math problems. A model that cannot solve a problem cannot tutor it.

📈 The main finding

📝 Various contemporary open-source VLMs perform multimodal undergraduate-level advanced math tutoring tasks well. The models empowered the agents to solve the 3D plotting calculus problems automatically. In this experiment, ❌ every agent without a tool failed, and ✅ every agent with the tool layer solved all 24 problems.

🧩 Why the results are not specially-tuned cases.

🔬 The agents were not specially tuned to solve these problems. The system prompt does not teach the agent any particular type of multimodal math problem. It defines only a general work flow: 👁️ read the problem image, 🧠 analyze step by step, 🧮 verify every calculation with Python, 🖼️ draw the plots, and 📄 write the boxed answer. The same process can serve a different problem type.

🚀 This property gives the agent its potential. With the same design, the agent can act as a general-purpose undergraduate-level advanced math AI teaching assistant. It reads, reasons, verifies, and plots, without special tuning per problem family.

📖 Key Terms

The terms below appear once in full, then by short name.

👁️ Vision-language model (VLM). A model that reads both text and images, such as the open-source models in this experiment.

💬 Language model (LLM). A neural network trained on text. It reads text and writes text. It reasons about symbols and equations but cannot touch a file or draw an image by itself.

🖼️ Multimodal tutoring. Tutoring in which the problem arrives as an image, such as a picture of a printed question, and the answer includes plots.

🤖 Agent. A program that loops. It asks the model for a step, runs tools the model requests, and gives the tool output back to the model. The loop ends when the model stops calling tools.

⚙️ DeepAgents. A framework for building such agents. It provides the loop and the built-in tools such as plan tracking and file access. MCMA uses DeepAgents as the outer layer.

🧰 Tool. A function the model can call. MCMA adds four custom tools: run_python, plot_pyplot, plot_pgfplots, and write_results.

🏆 MCMA. Math-Capable Multimodal Agent. It is the agent system tested here: a multimodal model plus DeepAgents plus the four custom tools.
