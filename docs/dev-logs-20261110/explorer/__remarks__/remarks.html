📋 The four recipes

We tried multiple math-agent recipes on 24 multi-variable calculus problems. 📌 All four recipes use DeepSeek Harness on the PC in PTC mode. The model runs on the Internet or on the HPC. The renderer changes between recipes.

  1. 🤖 [ DeepSeek Flash (Internet) + DeepSeek Harness (PC, PTC mode) + Python (numpy, matplotlib, sympy) + LaTeX (texlive 2026 CLI, latexmk) ]

    • ✅ Recipe worked.
    • ⏱ All problems solved in 1 hour 22 minutes. Reasonable speed. Reasonable token expense.
    • 📁 Raw data in ../../dev-logs-20261027/dsh-deepseek-flash/.
    • 💥 Agent crashed once. Manually resumed.
    • 🛠 Crash cause: multiple LaTeX compilations running in parallel drain memory.

  2. 🔧 [ Qwen3.6-27B (HPC/x****9) + DeepSeek Harness (PC, PTC mode) + Python (numpy, matplotlib, sympy) + Typst (typst CLI) ]

    • ❌ Recipe failed.
    • ⏱ All problems solved in 1 hour 31 minutes.
    • 🗑 Raw data makes no sense. Deleted.
    • ⚠ The LLM claimed work completed, but the Typst files produced are garbage. See ./qwen3.6-no-typst-support.png.
    • ✅ HPC VLLM server worked. Workspace: x****9.
    • 🔌 Server often refuses connection. Probably because the same process also worked grading tasks.
    • 🧠 Qwen3.6-27B does not know how to write Typst.

  3. 🤖 [ DeepSeek Flash (Internet) + DeepSeek Harness (PC, PTC mode) + Python (numpy, matplotlib, sympy) + HTML (KaTeX) ]

    • ✅ Recipe worked.
    • ⏱ All problems solved in 1 hour 11 minutes. Reasonable speed. Reasonable token expense.
    • 📁 Raw data in ../dsh-deepseek-flash/.
    • 📈 Solutions have good visual quality.

  4. 🧠 [ Qwen3.8-27B (HPC/y*****8) + DeepSeek Harness (PC, PTC mode) + Python (numpy, matplotlib, sympy) + HTML (KaTeX) ]

    • ✅ Recipe worked.
    • ⏱ All problems solved in 7 hours 46 minutes. Very low speed. Reasonable token expense.
    • 📁 Raw data in ../dsh-qwen3.8-27b-hpc/.
    • 🐢 1 subagent crashed with a \t\t\t... output loop. Its parent agent automatically recovers. See ./qwen3.8-output-loop.png.
    • 🛠 HPC A800 GPU driver only supports CUDA 12.8 or later. But the current precompiled VLLM only supports CUDA 13 or later.
    • ✅ Compiled VLLM 0.24.0 with CUDA 12.8 on the HPC.
    • 🖥 HPC VLLM server worked. Workspace: y*****8.
