Experiment Report · 2026-11-10

🧪 Four Recipes for 24 Calculus Problems

🧮 Two model families, two renderers, and one problem set. ✅ Three recipes gave usable solutions. ❌ One recipe gave garbage. ⏱ The fastest recipe took 71 minutes. 🐢 The slowest usable recipe took 7 hours 46 minutes. 📊 The renderer was the main risk, not the math. 💻 All four recipes run DeepSeek Harness on the PC.

⚡ Short answer

✅ The problem set is solved. 24 exercises from Stewart, Calculus: Early Transcendentals, Sections 15.7, 15.8, and 15.9. Each usable recipe gives one solution for each problem.

🧪 The recipe is the variable. The same 24 problems went through four recipes. Three recipes produced usable solutions. One recipe produced files that do not open as valid documents.

📌 All four recipes run DeepSeek Harness on the PC and Python (numpy, sympy, matplotlib) next to it. The model is served from the Internet API for DeepSeek Flash or from an HPC VLLM server for the Qwen models. Only the renderer and the model change.

📌 The times come from the operator remark file. The earlier log gives 76 minutes for the LaTeX recipe. The remark file gives 82 minutes. The difference is the start and end points of the clock.

💡 Main finding

🔧 HTML with KaTeX removes the renderer risk. The page is one file. The math, the fonts, and the figures are inside the file. No compile step runs on the machine. The LaTeX crash in the first recipe cannot occur.

🧠 A renderer is only safe when the model knows it. Qwen3.6-27B writes Typst code that looks plausible but is not valid. The run reported success. The files are not usable. A correct final claim needs a check of the output, not a check of the model text.

🐢 Speed does not follow from the output form. Qwen3.8-27B used the same HTML form as DeepSeek Flash. It took 6.6 times longer. The model and the server, not the renderer, set the speed.

📈 Detail is stable across the two usable HTML runs. DeepSeek Flash wrote 42,107 words in 24 solutions. Qwen3.8-27B wrote 43,417 words. Each solution has a notation table. 23 of the 24 Qwen3.8-27B solutions have a separate verification section.
