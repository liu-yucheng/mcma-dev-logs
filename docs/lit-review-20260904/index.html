🎯 Executive summary

This report reviews current research on math-capable multimodal AI agents. It focuses on research gaps and open problems that relate to a new agent with these capabilities:

  • 🎓 It teaches advanced mathematics on its own.
  • 👁️ It integrates vision-language models (VLMs).
  • 🛠️ It has a toolset for generating and revising plots.
  • 📈 It uses both matplotlib.pyplot and PGFplots for tasks such as calculus surface sketching.

These capabilities put the agent in several new research areas. The field moves fast. Important research gaps remain. The review found four gaps:

📊
1. A benchmarking void

No existing benchmark tests an agent's ability to do generative, iterative tasks such as undergraduate-level calculus surface sketching. Current benchmarks focus on discriminative or single-turn generative tasks. They do not test tool use, iterative revision, or pedagogical scaffolding.

📄
2. The PGFplots integration frontier

The literature shows a clear gap in agentic systems that can generate and revise plots with the LaTeX-native PGFplots package. Most systems use Python-based libraries such as matplotlib. These libraries have a simpler code-execution-feedback loop. The ability to control PGFplots is a useful edge. It also opens a mostly unexplored research area.

🧊
3. Nascent capabilities in visual reasoning and sketching

Sketching as a "chain of thought" for reasoning is an emerging idea. Current models, however, have severe limits in 3D spatial understanding. They show poor global structural reasoning. They fail to keep topological validity. They cannot read 3D space from 2D projections correctly. These limits are large hurdles for surface sketching in calculus.

🎓
4. The chasm of pedagogical ineffectiveness

A repeated theme in recent literature is that even capable models fail as teaching tools. Agents often cannot make grade-appropriate explanations. They cannot match diagrams to problem meaning. They cannot use effective scaffolding. The move from "problem solver" to "autonomous tutor" is a large, under-researched challenge.

The report examines these findings in order. It maps the current field. It also gives a structured guide to the open research questions the agent can answer. With these capabilities, the work can help solve these challenges in AI for education and scientific discovery.

📖 Key terms

The terms below appear once in full, then by short name.

👁️ Vision-language model (VLM). A model that reads both text and images, such as the open-source models discussed in this review. Also called a multimodal large language model (MLLM).

🤖 Agent. A program that loops: it asks the model for a step, runs the tools the model requests, and gives the tool output back to the model. The loop ends when the model stops calling tools.

🧮 Code-as-policy. A paradigm in which the model generates an explicit program (for example Python) that calls APIs or specialist modules to solve a visual task, instead of outputting the answer directly.

📈 matplotlib / pyplot. An imperative Python plotting library. Agents write code like plt.plot() and plt.savefig(); a code interpreter runs it and returns an image or an error message.

📄 PGFplots. A declarative LaTeX package for high-quality scientific plots, compiled into a PDF. Superior typographic consistency, but a harder challenge for agentic control.

🧊 Chain of thought (CoT). A prompting technique that elicits step-by-step reasoning. "Visual chain of thought" extends the idea to drawing diagrams as part of the reasoning process.

🧭 Scaffolding. A teaching strategy that breaks complex ideas into simpler steps and guides the student's learning process. The review finds current models universally weak at it.

🧪 Benchmark. A fixed set of problems used to measure a model or agent's capability. The review shows that current math benchmarks do not measure generative agentic tutoring tasks.
