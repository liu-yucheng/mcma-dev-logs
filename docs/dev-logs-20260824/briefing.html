Retry causes

MCMA agents retried 20 of 116 attempts. No retry came from a wrong mathematical result. The retry causes are:

  1. Rate limit. The API service reached the “tokens per minute” cap. The agent waited, and then it retried. The later attempt succeeded.
  2. Invalid output format. The model produced a LaTeX or result block that did not parse. The agent rewrote the block. The later attempt succeeded.

We call an attempt “Agents worked as expected” when the model produces multimodal contents, that is text and image, as the final solution of a problem. We use this term regardless of the mathematical correctness of the output. We need to manually compare model output against canonical solutions to check mathematical correctness.

Parameter size does not affect tool-calling capability

The parameter size of a model appears to have no correlation with its ability to produce multimodal output with the agent tools. This holds regardless of the mathematical correctness of the output.
