How to use the explorer

Each of the two independent panels is styled like a file explorer window. The toolbar on top offers navigation buttons (back, forward, up, home); the address bar shows the current location with / as the separator and is editable — type a path such as mcma-Kimi-K2.7-Code/calculus-12.6.3 and press Enter to jump straight to it. The single main view lists the subdirectories and files of the current folder, with . (current folder) and .. (parent folder) at the top. Click a folder to open it or click a leaf (canonical-solution.html, remarks.html, qna.html) to view it in the panel’s viewer — everything opens with a single click. Both panes start at the root, which holds canonical-solutions/ and the model directories.

The folders mirror explorer/: canonical-solutions/<problem>/canonical-solution.html, <model>/<problem>/remarks.html and <model>/<problem>/<chat>/qna.html. Each chat transcript is also reachable through a shortcut leaf at <model>/<problem>/qna_<timestamp>.html, which redirects to the deep qna.html.
