Experiment Report · 2026-10-27

🧮 DeepSeek Harness Solves 24 Calculus Problems

The DeepSeek Harness standard agent solved all 24 problems. It made 49 figures and 24 PDF solutions. It reproduces the MCMA result with public plugins and no new agent code. The run used 76 minutes, 2,298 steps, and 236.4 million recorded tokens.

← ⌂ 🔬 Overview 🤖 Agents 📊 Results Briefing 🔍 Results Explorer 🗺 Future Plans

🧬 Reproduction in 4 weeks

📌 From Jun 29 to Sep 29, 2026, the MCMA project built math-capable multimodal agents on DeepAgents and LangChain. In the 4 weeks before this log, the operator rebuilt the same functions on DeepSeek Harness with public plugins. The operator did not write code for the agent.

✅ The new agent uses the same workflow: read the problem image, solve, verify with Python, draw the figures, compile the PDF, and check the result. Each solution also teaches the reader how to solve similar problems.

⚡ Short answer

✅ Yes. The agent solved all 24 problems. Each problem has a LaTeX solution, a compiled PDF, Python verification scripts, and at least two figures. The setup did not use a special prompt for one problem type. It used one general workflow.

📌 Parallel work. The parent agent started 8 subagents. Each subagent got 3 problems. Two problems needed a second pass. The parent started 2 more single-problem agents.

💰 Cost. The recorded cost is $3.77. This is about 3.1 times the peak-hour cost of the earlier MCMA deepseek-flash run.

🪙 Tokens. The session recorded 236.4M tokens. 97.3% are cache reads. New input and output are 6.4M tokens.

📚 Teaching. Every solution explains the symbols and shows how to solve similar problems. This is a prompt rule, not an optional extra.

🐢 Overhead. The remark file reports 3 times more tokens and 3 times more time. The cause is the DSH PowerShell support: recurring command-exception cycles. The Future Plans chapter gives the fix.
