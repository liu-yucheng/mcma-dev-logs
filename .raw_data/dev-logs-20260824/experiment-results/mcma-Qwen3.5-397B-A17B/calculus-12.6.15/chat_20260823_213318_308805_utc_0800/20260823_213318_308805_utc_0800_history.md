### `plot_pgfplots(latex_code: str) -> str`

Draw PGFplots / tikz plots by compiling `latex_code`.
Save `latex_code` to agent memory path `/tool_calls/plot_pgfplots_<timestamp>/<timestamp>.tex`.
Compile `latex_code` to a PDF file at agent memory path `/tool_calls/plot_pgfplots_<timestamp>/<timestamp>.pdf`.
Convert the compiled PDF file to a PNG image at agent memory path `/tool_calls/plot_pgfplots_<timestamp>/<timestamp>.png`.

Notes:

- Draw 1 plot at a time. Draw multiple plots with multiple tool calls. Do not combine plots together unless it is necessary.
- For each pyplot plot you create with `plot_pyplot`, you must also draw a corresponding PGFplots / tikz plot.
- For each pyplot 2D / 3D plot, you must draw a corresponding PGFplots / tikz 2D / 3D plot with the following commands.
  - \\addplot
  - \\addplot+
  - \\addplot3
- The styling of each PGFplots / tikz plot must be close to its corresponding pyplot plot.
- `latex_code` must be a complete LaTeX document and compile with `pdflatex / lualatex` without errors.

Example `latex_code`:

```latex
\\documentclass[border=10pt]{standalone}
\\usepackage{pgfplots}
\\usepgfplotslibrary{colormaps}
\\pgfplotsset{trig format plots=rad}
\\begin{document}
\\begin{tikzpicture}
\\begin{axis}[
    domain    = -4:4, samples    = 70,
    y domain  = -4:4, samples y  = 70,
    colormap/viridis high res, grid]
    \\addplot3[surf] { cos(sqrt(x^2+y^2)) };
\\end{axis}
\\end{tikzpicture}
\\end{document}
```

Args:
  latex_code (str): PGFplots / tikz LaTeX code of the plot.

Returns:
  str: A JSON string with the following format.

  ```json
  {
    "successful": <_:bool>, # Whether the tool call is successful.
    "error_messages": <_:str>, # Error messages, if any.
    "mem_dir": <_:str>, # Agent memory directory of the tool call.

    "pdf_mem_path": <_:str>, # Agent memory path of the compiled pdf file.
    "png_mem_path": <_:str>, # Agent memory path of the converted png file.
  }
  ```

# Solution: Identifying and Sketching the Surface $-x^2 + 4y^2 - z^2 = 4$

## Step 1: Rewrite the Equation in Standard Form

To identify the surface, we rewrite the equation in standard form:

$$-x^2 + 4y^2 - z^2 = 4$$

Dividing by 4:

$$-\frac{x^2}{4} + y^2 - \frac{z^2}{4} = 1$$

Rearranging:

$$y^2 - \frac{x^2}{4} - \frac{z^2}{4} = 1$$

Or equivalently:

$$\frac{y^2}{1^2} - \frac{x^2}{2^2} - \frac{z^2}{2^2} = 1$$

This is the standard form of a **hyperboloid of two sheets** with the $y$-axis as its axis of symmetry.

## Step 2: Analyze Traces

### Trace in the plane $y = k$ (horizontal traces):

Setting $y = k$:
$$-x^2 + 4k^2 - z^2 = 4$$
$$x^2 + z^2 = 4k^2 - 4 = 4(k^2 - 1)$$

- For $|k| > 1$: We get circles (or ellipses in the general case) with radius $\sqrt{4(k^2-1)}$
- For $|k| = 1$: We get a point (the vertex)
- For $|k| < 1$: No real solution (the surface doesn't exist here)

### Trace in the plane $x = 0$ (yz-plane):

Setting $x = 0$:
$$4y^2 - z^2 = 4$$
$$\frac{y^2}{1} - \frac{z^2}{4} = 1$$

This is a **hyperbola** opening along the $y$-axis.

### Trace in the plane $z = 0$ (xy-plane):

Setting $z = 0$:
$$-x^2 + 4y^2 = 4$$
$$\frac{y^2}{1} - \frac{x^2}{4} = 1$$

This is also a **hyperbola** opening along the $y$-axis.

## Step 3: Identify Key Features

- **Type**: Hyperboloid of two sheets
- **Axis of symmetry**: $y$-axis
- **Vertices**: $(0, \pm 1, 0)$
- **Exists for**: $|y| \geq 1$
- **Cross-sections perpendicular to $y$-axis**: Circles (ellipses in general)
- **Cross-sections containing the $y$-axis**: Hyperbolas

## Step 4: Sketch the Surface

The surface consists of two separate sheets:
1. One sheet for $y \geq 1$ (opening upward along the positive $y$-axis)
2. One sheet for $y \leq -1$ (opening downward along the negative $y$-axis)

Each sheet is bowl-shaped and symmetric about the $y$-axis. The sheets never touch; there's a gap between $y = -1$ and $y = 1$.

## Final Answer

The surface $-x^2 + 4y^2 - z^2 = 4$ is a **hyperboloid of two sheets** with the $y$-axis as its axis of symmetry.
