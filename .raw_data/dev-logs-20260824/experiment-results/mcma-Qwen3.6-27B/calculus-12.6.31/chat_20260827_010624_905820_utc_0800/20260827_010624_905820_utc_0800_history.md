### `plot_pgfplots(latex_code: str) -> str`

Draw PGFplots / tikz plots by compiling `latex_code`.
Save `latex_code` to agent memory path `/tool_calls/plot_pgfplots_<timestamp>/<timestamp>.tex`.
Compile `latex_code` to a PDF file at agent memory path `/tool_calls/plot_pgfplots_<timestamp>/<timestamp>.pdf`.
Convert the compiled PDF file to a PNG image at agent memory path `/tool_calls/plot_pgfplots_<timestamp>/<timestamp>.png`.

Notes:

- Draw 1 plot at a time. Draw multiple plots with multiple tool calls. Do not combine plots together unless it is necessary.
- For each pyplot plot you create with `plot_pyplot`, you must also draw a corresponding PGFplots / tikz plot.
- For each pyplot 2D / 3D plot, you must draw a corresponding PGFplots / tikz 2D / 3D plot with the following commands.
  - \\addplot
  - \\addplot+
  - \\addplot3
- The styling of each PGFplots / tikz plot must be close to its corresponding pyplot plot.
- `latex_code` must be a complete LaTeX document and compile with `pdflatex / lualatex` without errors.

Example `latex_code`:

```latex
\\documentclass[border=10pt]{standalone}
\\usepackage{pgfplots}
\\usepgfplotslibrary{colormaps}
\\pgfplotsset{trig format plots=rad}
\\begin{document}
\\begin{tikzpicture}
\\begin{axis}[
    domain    = -4:4, samples    = 70,
    y domain  = -4:4, samples y  = 70,
    colormap/viridis high res, grid]
    \\addplot3[surf] { cos(sqrt(x^2+y^2)) };
\\end{axis}
\\end{tikzpicture}
\\end{document}
```

Args:
  latex_code (str): PGFplots / tikz LaTeX code of the plot.

  str: A JSON string with the following format.

  ```json

  }
  ```

### 1. Reduce to Standard Form
The given equation is:
$$x^2 + 2y - 2z^2 = 0$$

First, isolate the linear term $2y$ by moving the squared terms to the other side:
$$2y = 2z^2 - x^2$$

Next, divide the entire equation by 2 to solve for $y$:
$$y = z^2 - \frac{x^2}{2}$$

This can be written explicitly in the standard form for a hyperbolic paraboloid:
$$y = \frac{z^2}{1^2} - \frac{x^2}{(\sqrt{2})^2}$$

### 2. Classify the Surface
The standard form $y = \frac{z^2}{c^2} - \frac{x^2}{a^2}$ corresponds to a **hyperbolic paraboloid**. 
- The axis of symmetry is the $y$-axis (the axis corresponding to the linear term).
- The surface has a saddle shape.

### 3. Sketching the Surface (Analysis of Traces)
To sketch the surface, we examine its traces (cross-sections) in coordinate planes:

*   **Traces in planes $x = k$ (parallel to $yz$-plane):**
    Substituting $x = k$ gives $y = z^2 - \frac{k^2}{2}$. These are **parabolas opening upward**.
*   **Traces in planes $z = k$ (parallel to $xy$-plane):**
    Substituting $z = k$ gives $y = k^2 - \frac{x^2}{2}$. These are **parabolas opening downward**.

    Substituting $y = 0$ gives $0 = z^2 - \frac{x^2}{2}$, which factors to $z = \pm \frac{x}{\sqrt{2}}$. These are **two intersecting lines** through the origin.

The combination of upward-opening parabolas in one direction and downward-opening parabolas in the perpendicular direction creates the characteristic "saddle" shape of a hyperbolic paraboloid.
